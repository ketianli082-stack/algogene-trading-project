# EXP-005 — V1.1 EMA200 + Donchian baseline

Role: Development. Requested period: January 2021–December 2023. Status: NOT RUN at registration; append observed outcome after the cloud execution.

Pre-registered parameters: H4; EMA200; 20-bar high channel entry; 10-bar low channel exit; long-only; fixed 0.01 lot; initial capital 10000 USD; leverage 1; no pyramiding. No parameter search in this experiment.

At each H4 event, query 260 H4 bars. Only timestamps strictly earlier than the event are eligible, introducing a deliberate bar delay relative to contemporaneous close signals. Require at least 201 eligible observations at startup; otherwise halt without trading. Seed EMA with the first 200 closes, then update recursively once per new bar. Donchian channels exclude the signal bar. Enter if signal close exceeds both the previous-20 high and EMA; exit if signal close falls below previous-10 low or EMA. Order fills determine position state. Pending orders block repeat submissions. Rejected/unrecognized callbacks halt new trading. Close any remaining position at the first event at/after 2023-12-31 16:00 in platform event time.

Instrument/cost assumptions: fixed 0.01 **lot**, not an independently verified BTC-unit claim; capital precheck assumes contractSize=1. Contract metadata is not yet independently verified. No explicit commission/slippage/funding override; effective platform costs remain UNKNOWN. Returned P/L must be described as platform-reported under platform settings, not all-in verified net return. This is a backtest baseline without ATR sizing or a protective price stop; maximum loss is not capped at 2%. These are later ablations, not invisible additions to V1.1.

Evidence needed: effective dates and dataset=240, historical query response, warm-up availability, fills, strategy error markers, platform P/L/Sharpe/drawdown, actual cost settings. If the period or dataset changes, exclude it from matched comparison. No 2024/2025 queries are authorized by this experiment.
