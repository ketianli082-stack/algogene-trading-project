# BTC 单资产算法交易研究路线 / Research roadmap

目标：以 ALGOGENE 原生综合评分、风险调整收益与真实交易证据为核心，分阶段进行可复现的机制消融，而不是仅追求训练样本中的高分。

## 统一实验设计
BTCUSD；60min；2021-01 至 2024-12 为开发集；2025 作为本研究路线的保留检验期（既往项目接触过该年，因此不宣称全局严格未见）；USD 10,000、1x、long/flat、目标仓位50%。配置和策略代码都不添加固定交易费用字段；百分比费用与滑点单独分析。每组独立 GitHub Actions、独立平台 Backtest ID 及 artifact；顺序提交，不重复盲目重试。

## 每轮研究流程
1. 固定基准及研究假设，每次尽量只改变一个机制。
2. 使用严格历史信息，核验成交、费用口径、部署配置、日志。
3. 对比总分、Sharpe、最大回撤及持续时间、收益、交易笔数、配对后的胜率、盈亏比、年度表现、盈利集中度；检查大额亏损和失败信号。
4. 按手续费率及滑点做独立敏感性分析，避免高频无效交易。
5. 保留失败、零成交和候选否决理由，不能只汇报最佳实验。
6. 冻结策略后再用 2025 年检验，不能用其结果回头选择参数后仍声称独立检验。

已有 2021–2024 四年结果参与 ADX 参数筛选，2024 不再是独立内部验证。后续可采用滚动或分阶段稳健性诊断，明确其仍属开发样本。

## LLM 阶段原则
先完成无 LLM 的可复现基准；模型输入仅限决策前可得信息，固定模型/提示词/结构化输出、记录调用及失败回退。对比传统市场状态分类器与 LLM 版本，控制交易成本、延迟与相同数据窗口。若平台不能可靠调用模型，可使用严格按时间生成且冻结的离线信号，但不得把事后信息带入历史决策。
