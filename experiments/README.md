# 正式实验（S/R/E 分担，E 统一登记）

> 阶段说明：11 月 17 日前每人独立完成完整基础版本，见 candidates/。本文角色 S/R/E 仅用于选型后的主策略，实际成员届时重新分配。不按本文提前限制各人研究范围。

运行前登记实验 ID、目的、负责人、准确运行代码提交、配置、区间用途、成本、预热及初始持仓；运行后补充 Backtest ID、输出位置、状态和异常。当前没有已完成实验。

## 责任

S：信号及参数；R：仓位、止损、风险资金；E：基准、成本及执行敏感性。每人设计、分析、解释对应实验；E 统一设置记录，平台操作人不决定研究归属。

## 比较设计

共同基础安全约束保持一致，按需要比较基础信号、加入波动率仓位、再加入止损、最后加入单一过滤条件。需要识别某项贡献时只改变该项；不要把同时改变仓位和止损的差异归因于其中一项。风险水平、资金占用不同时同时报告。

## 成本与执行

成本配置可调整时重新运行，反映仓位和资金反馈。只能后处理时标记为近似，不宣称等同完整成交模拟。避免重复计入已含点差。检查延迟、跳空及分钟内路径未知的影响。

## 输出及交接

完整包按实际可获得内容保存代码、配置、净值、交易、日志、汇总和说明。R 获取结果完成风险资金分析，E 计算绩效，S 获取结果写摘要。缺数据明确限制，不补造，不以截图推算不存在的完整序列。

开发、验证、最终测试角色分开，记录所有试验。测试前冻结；测试后改动及重跑如实披露。无需他人审批，负责人自行检查并存证。
