# BAS-002A：现货—永续基差均值回归统计验证（Pilot）

**状态：NOT RUN（初次提交时）**。该实验只读 ALGOGENE 历史报价，不提交任何交易或云端回测，不使用 `TradeCost`。

## 研究假设
H1：异常正基差（历史前168条观测 Z-score ≥ 2）后，在24/48/72小时的未来基差变化均值为负。
H2：未来价差缩小的样本占比可能高于50%，但必须以真实数据决定，不预设统计显著性。

## 数据及第一轮
BTCUSD/BTCUSDM、ETHUSD/ETHUSDM；ALGOGENE API `/rest/v1/history_price`，`interval=H`，每品种请求720条，首批锚点为2024-12-31。必须以实际返回日期和字段为准。用共同 UTC 时间戳匹配，按 `10000×(F−S)/S` 构造基差；若仅返回 `close`，标明 **close proxy**，不视为可执行基差，不应计算真实PnL。

## 模型
窗口只使用信号时刻以前的168条观测；过滤超过6小时的最新数据缺口及210小时以上的窗口跨度；分母下限2bp；信号规则 z≥2 且正基差。对每个信号，查找严格未来 +24/+48/+72 小时相同时间戳的基差，不用最近日期近似替代。若历史API返回的是日线或无时间戳数据，不得伪造小时数据。统计变化 bp（未来−当前）及变化为负占比。

## 质量与局限
- 这是**统计信号研究**，不是四腿报价交易回测；结果不扣费用、不包含Funding、融资成本、保证金或订单延迟。
- 第一轮只覆盖锚点附近的一小段样本，不代表完整2021—2024或2025测试集。
- 同一信号附近的连续小时高度重叠，观察并不独立；下一轮需要按事件去重、块自助抽样置信区间和不同市场时期稳健性。
- 若出现历史数据不足、字段错误、BTC/ETH时间未同步或真实信号太少，结果应标记`INSUFFICIENT_SIGNAL_OR_HISTORY`，不作收益结论。
- 2025 历史数据已有过研究使用，不能无条件称之为独立样本外。

## 运行与输出
GitHub Actions：`.github/workflows/bas002a-mean-reversion.yml`，push工作流文件时自动启动，亦可手动触发。
保存到 artifact：`summary.json`、`btc_signals.csv`、`eth_signals.csv`。输出含 API 实际数据覆盖、原始可用字段名称、BTC/ETH共同时间戳条数、24/48/72小时信号数、平均及中位价差变化、收敛占比和错误原因。
不打印API密钥、不上传完整账号请求及凭据。
