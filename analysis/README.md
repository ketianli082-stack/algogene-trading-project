# 分析工具

> 阶段说明：11 月 17 日前每人独立完成完整基础版本，见 candidates/。本文角色 S/R/E 仅用于选型后的主策略，实际成员届时重新分配。不按本文提前限制各人研究范围。

- performance/：E 制作结果读取、收益指标、基准和图表程序，负责基准、成本、执行敏感性实验。
- risk_capital/：R 制作风险资金程序或可复算表，负责仓位、止损、压力、资金和容量实验。
- S 独立负责信号参数研究，可在 signal/ 保存分析，不把工作默认交给 E。

每个成果标明负责人、实验 ID、来源、口径及限制。早期可用明确标记的示例数据开发，但不得进入最终报告结果。当前没有实际程序或结果。
