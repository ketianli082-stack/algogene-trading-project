# ALGOGENE Trading Research Project

三人量化交易课程项目。当前为规划阶段：尚未确定最终交易工具、没有已验证策略或正式回测结果。截止时间：2026 年 11 月 27 日 23:59（HKT）。

## 先看这三份文件

1. [老师全部问题与负责人](docs/teacher_questions.md)：28 项研究问题及基础信息，逐题对应动作和证据。
2. [三人任务与交付清单](docs/team_roles.md)：谁做什么、交什么、需要什么输入。
3. [完整执行方案](docs/execution_plan.md)：从平台核查到最终提交的过程。

## 唯一负责人

| 成员 | 报告部分 | 工作责任 |
| --- | --- | --- |
| A（35 分） | 执行摘要、实现细节 | 策略假设、交易规则、完整脚本，实施 B 的风险资金政策 |
| B（35 分） | 风险管理、资金管理 | 风险识别、风控规格、仓位、最低资金、流动性、规模和容量计算 |
| C（30 分） | 回测表现、实盘预期 | 平台数据能力、正式实验、绩效图表、经纪商条件、报告整合和提交 |

实际成员待分配。每人完成自己章节的研究、计算和正文。C 整合报告，不代写 A/B 内容。不设置复核人或审批步骤；负责人自行完成必要的正确性检查。
