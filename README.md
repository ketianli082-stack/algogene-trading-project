# ALGOGENE Trading Research Project

三人小组量化交易课程项目：研究、实现并评价一套可在 ALGOGENE 复现的交易策略。

**当前状态：研究规划阶段，尚无正式回测结果。** 初步方向为波动率调整的趋势突破；品种、参数和成本待核查。计划使用 2021—2023 年开发、2024 年验证、2025 年最终测试。截止时间为 2026 年 11 月 27 日 23:59（HKT）。

## 三人角色

| --- | --- | --- |
| A：策略与平台 | 规则、代码、订单、风控、平台执行 | 策略规格、脚本、代码快照 |

## 使用方法

1. 三人阅读执行方案，在团队分工中确认角色。
2. 用 Issues 记录任务、负责人、截止时间和验收条件。
3. 先完成数据核查和最小交易验证，再进行策略实验。
4. 每次修改通过分支及 Pull Request，由另一人复核。
5. 正式实验记录准确提交编号、配置、平台回测 ID 和结果位置。
6. 最终代码、参数、报告和回测保持一致，提交前冻结版本。

目前仓库没有可运行策略，也没有已验证参数。目录说明文件不代表已经完成对应研究。

## 公开范围

本仓库公开项目规划及后续经确认可公开的研究材料。不上传凭据、学生 UID、个人联系方式、账户资金信息或未经授权的课程数据。原始行情、完整日志、大型输出和共同编辑的报告放在团队受限共享空间；不要在公开仓库写入可直接访问私人资料的分享链接。

报告与大型文件使用共享空间；GitHub 管理代码、规格、实验索引与评审。公开可见不等于授予开源许可，本次初始化不添加许可证，后续由团队决定。
