# V8.1 策略原理与参数
## 1. 核心假设
当永续合约相对现货出现统计上异常的**正基差**时，以等量现货多头和永续空头构建组合；如果基差缩窄，则价差变动可产生毛收益。永续合约不具备传统到期期货的必然到期收敛机制，不保证盈利。

## 2. 标的与频率
BTCUSD / BTCUSDM；ETHUSD / ETHUSDM；ALGOGENE 60 分钟报价。必须核实合约规格、计价和账户结算模式，不能仅凭名称断言是真实交易所永续产品。

## 3. 计算公式
- 中间价基差(bp)：10000 × (永续中间价 − 现货中间价) / 现货中间价。
- 可执行开仓基差(bp)：10000 × (永续 Bid − 现货 Ask) / 现货中间价。
- 可执行平仓基差(bp)：10000 × (永续 Ask − 现货 Bid) / 现货中间价。
- Z = (当前中间价基差 − 先前 168 个有效小时观测的均值) / max(标准差, 2bp)。
- 目标基差 = max(历史均值, 0)。

## 4. 开仓判定（同时满足）
Z ≥ 2；可执行正溢价 ≥ 30bp；开仓基差 − 目标基差 ≥ 20bp；两腿当期报价有效；资金、持仓、冷却期及异常停机条件合规。当前样本在计算信号之后才进入历史窗口，防止同小时样本前视。

## 5. 退出
- 平仓基差 ≤ 目标基差且组合预估清算 PnL > 0：收敛获利；
- 预估清算 PnL ≤ −初始现货腿名义金额的 75bp：亏损止损；
- 组合从创建起 ≥ 72 小时：发出退出请求，非强制保证成交；
- 开仓超过 2 小时或订单异常：尝试安全退出。

## 6. 仓位
单组合双腿总名义敞口 ≤ 40% NAV；总组合 ≤ 80% NAV；每组合计划风险 ≤ 0.25% NAV；最低名义数量向下取整至 0.0001 单位；可用余额保留余量；完成平仓后同币种冷却 6 小时。**风控阈值是计划预算，不是亏损保证上限。**

## 7. V8.1 相对 V8
完整对冲仍存在且两腿均无待平订单时，须等待两个最新有效报价才提交正常双腿平仓；先登记全部待平仓保留，再发送订单。若发生拒单/不确定回报，不盲目重复下单；记录报价等待、单边暴露和暂停开仓状态。但两笔订单并非原子交易，仍会有单腿成交风险。

## 8. 尚未验证的假设
手续费、滑点、资金费率、合约保证金规则、成交冲击和可用历史数据。策略日志里的 gross PnL 不等于平台扣费后净 PnL。
