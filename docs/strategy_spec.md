# 策略规格（S 负责）

> 阶段说明：11 月 17 日前每人独立完成完整基础版本，见 candidates/。本文角色 S/R/E 仅用于选型后的主策略，实际成员届时重新分配。不按本文提前限制各人研究范围。

状态：待平台核查及实际研究填写。趋势突破只是候选，不是已选定或已验证方案。

## 1. 假设与来源（E01、E02、I03、I04）

待填写：经济直觉、可检验假设、公开方法引用、失效条件。

## 2. 工具与数据（E03、E04）

待填写：具体工具类型、代码、数据范围、字段、时区、交易日历、价格调整、合约单位。

## 3. 交易规则（I01、I02）

待填写：公式、参数、已完成 K 线定义、窗口、信号/成交时间、开仓、退出、重复信号与期末处理。

## 4. 风险资金实现

输入为 R 的 risk_capital_spec.md 及 R 编写的可接入模块。S 负责平台字段适配、调用与订单动作，R 负责数量、风险规则及模块自身检查。逐项写明实现位置和行为；程序必须同时满足信号、风险与资金约束。下单不等于成交，平仓请求不等于归零。

## 5. 假设与运行限制（I05）

待填写：成本、点差、滑点、止损模拟、分钟内路径、行情过期、拒单、重启及恢复。平台未支持的功能不能写成已实现。

S 的退出规则是市场信号退出，R 的退出规则是保护性止损和账户风险退出。优先级写入规格，避免重复平仓。E 提供输出需求并编写绩效工具，S 仅接入必要记录点。

## 6. 技术验证与版本

保存指标、数量换算和一笔开平仓的自行计算；记录代码、配置、平台 ID 与异常修复。不设他人审批。上述技术结果传给 E 登记，不等同正式收益结论。
