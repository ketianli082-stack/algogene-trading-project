状态：研究工作表，所有具体工具、金额、比例和限额待确定；当前没有已实施规则或实验结果。

逐项说明本策略的风险机制：假突破和连亏、跳空、无法退出、点差扩大、相关性集中、融资/保证金、模型与系统故障。每个压力情景列明假设、所需数据、计算或回测方法、结果位置和局限。历史回撤不是未来损失上限。

## 3. 数量与资金（K01—K03）

确定账户货币、合约乘数、数量单位与步长、汇率、止损距离和保证金。按风险预算计算数量后，再施加资金和敞口上限；最小数量超预算则跳过。账户杠杆不能重复乘入盈亏或数量。

计算平均/最大资金占用、空仓时间和缓冲。最低资金综合最小单位止损风险、保证金、费用及缓冲；合理运作规模另行分析。使用真实规格给出至少一个可复算例子。

## 4. 规模与容量（K04、K05）

对多个资金情景计算舍入、目标风险、实际敞口、保证金与订单大小。研究成交量、点差、参与率或市场深度；无法取得时不能宣称精确容量。区分平台允许的数量与市场可承受规模。

## 5. 实验与交接

B 给 C 列明风险问题、基线、变化、区间及所需输出；C 登记和运行，B 用输出完成分析。至少说明连亏、跳空和不利执行的影响；工具特有风险按需增加。

B 输出 report/03、04，另给 C 资金规模、杠杆、容量和剩余风险的明确结论，用于 L04—L06。不设置复核人。
