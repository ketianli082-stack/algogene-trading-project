# 风险与资金规格（R 负责）

> 阶段说明：11 月 17 日前每人独立完成完整基础版本，见 candidates/。本文角色 S/R/E 仅用于选型后的主策略，实际成员届时重新分配。不按本文提前限制各人研究范围。

状态：研究工作表，所有具体工具、金额、比例和限额待确定；当前没有已实施规则或实验结果。

## 1. 风险识别与最坏情景（R01、R02）

逐项说明本策略的风险机制：假突破和连亏、跳空、无法退出、点差扩大、相关性集中、融资/保证金、模型与系统故障。每个压力情景列明假设、所需数据、计算或回测方法、结果位置和局限。历史回撤不是未来损失上限。

## 2. R 制作并交给 S 接入的模块（R03）

| 控制 | R 必须确定的内容 | 当前状态 |
| --- | --- | --- |
| 单笔风险 | 权益口径、比例、数量公式 | 待定 |
| 止损 | 距离、更新、触发、跳空处理 | 待定 |
| 敞口上限 | 单品种、组合、同时持仓和相关暴露 | 待定 |
| 资金检查 | 现金、可用余额、保证金、缓冲和不足时动作 | 待定 |
| 暂停 | 损益口径、日界时区、阈值、平仓或停止开仓 | 待定 |
| 恢复 | 时间、条件、自动或人工 | 待定 |

明确哪些规则采用、哪些不采用及原因。R 在正式策略回测前编写并自行检查风险和仓位函数或可嵌入代码段，附输入输出、单位、调用时机、异常和样例；S 负责平台字段适配与接入，版本交给 E 登记。未实现的措施单列，不写为现有控制。

## 3. 数量与资金（K01—K03）

确定账户货币、合约乘数、数量单位与步长、汇率、止损距离和保证金。按风险预算计算数量后，再施加资金和敞口上限；最小数量超预算则跳过。账户杠杆不能重复乘入盈亏或数量。

计算平均/最大资金占用、空仓时间和缓冲。最低资金综合最小单位止损风险、保证金、费用及缓冲；合理运作规模另行分析。使用真实规格给出至少一个可复算例子。

## 4. 规模与容量（K04、K05）

对多个资金情景计算舍入、目标风险、实际敞口、保证金与订单大小。研究成交量、点差、参与率或市场深度；无法取得时不能宣称精确容量。区分平台允许的数量与市场可承受规模。

## 5. 实验与交接

R 负责风险问题、基线、变化、区间、所需输出及实验分析，E 统一登记；运行者按账户权限安排。至少说明连亏、跳空和不利执行的影响；工具特有风险按需增加。

S 负责市场信号退出，R 负责保护性止损和账户风险退出；同时触发的优先级由 R 写明，S 在订单层落实。R 将数量与风险模块放 src/risk/，资金及风险分析放 analysis/risk_capital/。

R 输出 report/03、04，另给 E 资金规模、杠杆、容量和剩余风险的明确结论，用于 L04—L06。不设置复核人。
